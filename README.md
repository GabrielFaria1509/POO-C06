# ☕ POO — Programação Orientada a Objetos em Java

Este repositório foi desenvolvido para organizar, documentar e centralizar todos os laboratórios práticos, resoluções de listas de exercícios e códigos de estudos desenvolvidos ao longo da disciplina de **Programação Orientada a Objetos (POO)** no **Inatel**.

O objetivo deste espaço é consolidar o domínio do ecossistema **Java** e a aplicação prática de padrões de projetos arquiteturais fundamentais baseados no paradigma orientado a objetos.

---

## 🛠️ Tecnologias e Ferramentas utilizadas

* **Linguagem Core:** Java (Sintaxe robusta, tipagem estática e fortemente orientada a objetos).
* **Plataforma:** Java JDK (Java Development Kit).
* **IDE:** IntelliJ IDEA.

---

## 🧠 Conteúdo Prático Desenvolvido

O repositório contém diretórios estruturados com exercícios que cobrem o fluxo completo de tópicos da matéria:

1. **Introdução à Plataforma & Sintaxe:** Fundamentos do método `main`, variáveis primitivas e estruturas de controle de fluxo.
2. **Estruturas de Dados:** Manipulação de Arrays unidimensionais e multidimensionais.
3. **Modolarização em Objetos:** Criação de classes, instanciação de objetos, métodos dinâmicos e construtores.
4. **Encapsulamento e Visibilidade:** Controle e restrição de acesso através de modificadores (`private`, `public`, `protected`) e métodos seletores (*Getters/Setters*).
5. **Reutilização de Código & Design:** Implementação prática de Herança e Polimorfismo para acoplamento flexível.
6. **Abstração Avançada:** Classes Abstratas e definição de contratos comportamentais rígidos por meio de **Interfaces**.
7. **Estrutura de Coleções (Collections API):** Gerenciamento dinâmico de dados em memória usando Listas, Conjuntos e Mapas.
8. **Robustez de Software:** Tratamento de erros em tempo de execução com blocos de Exceções (`try-catch-finally`).
9. **Manipulação de Arquivos (Java NIO):** Entrada e saída de dados persistentes no sistema de arquivos de forma moderna.
10. **Programação Concorrente:** Introdução ao processamento assíncrono e paralelismo através de **Threads**.
